# Pre-share audit (22 Oct 2026)

Production build served locally. Pages audited:
- Home, Investments, Criteria, Investors, Team, Values, News
- One company news page, Privacy, two posts, and an unknown URL

Widths tested: 320, 360, 390, 768, 1024, 1366 and 1920px.

## Results

| Area | Result |
| --- | --- |
| Responsive | No horizontal scrolling at any width. No text overflow and no broken images. The header switches to the hamburger menu below 1024px, and the drawer works at every width. |
| Accessibility (axe-core, WCAG 2.2 AA) | 0 violations on all pages at 390 and 1366px, after the fixes below. Lighthouse accessibility score: 100. |
| Links | 185 pages and 380 assets all return 200. Old WordPress URLs redirect. |
| 404s | Unknown URLs return HTTP 404 with a branded page. |
| Form | Submits with and without JavaScript, and required-field messages show. Delivery is on hold: inquiries are only logged until `EMAIL_PROVIDER=resend` is configured. |
| Console | No JavaScript errors. |
| Lighthouse, desktop | Performance 99–100, Best practices 100. |
| Lighthouse, mobile | Performance 86–92, Best practices 100. Mobile LCP is about 3.3s on a throttled 4G profile. |
| SEO | Every page has a unique title, description and canonical URL, and there is a sitemap with 184 URLs. Lighthouse SEO scores 69 only because staging is deliberately `noindex`; the live site (`SITE_ENV=production`, set on Hostinger) is indexable. |

## Fixed in this pass

- **Tap targets:** the top-bar phone and email links, the contact-form radio buttons (now 44px rows) and the testimonial company links meet the 24px minimum.
- **Contrast:** footer headings now use `blue-stat`, at 4.55:1 (they were 4.46:1). The staging "Draft" marker is now readable on dark bands.
- **Landmarks:** the contact top bar is now a labelled landmark.
- **Heading order:** Investments and the company news pages no longer jump from h1 to h3.
- **Story cards:** they sit in two columns on tablets, so long company names no longer overflow at 768px.
- **Meta descriptions:** each page now has its own description. Previously every page reused the same 281-character fallback.
- **Mobile hero video:** phones get a 1.3 MB 720p encode instead of the 3.3 MB 4K file. Local Chromium has no H.264, so it fetches both; real Chrome and Safari fetch only one.
- **Soft 404s:** these are fixed, and the not-found page is now branded.
